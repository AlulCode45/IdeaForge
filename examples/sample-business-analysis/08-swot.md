# SWOT & TOWS Matrix - BengkelKu SaaS (Sample)

| Dimensi | Poin Utama |
|---|---|
| **Strengths** | Fokus vertikal bengkel motor (komisi mekanik + riwayat nopol), gross margin SaaS 86,4%, payback CAC 1,6 bulan (`11`, `15`) [Estimate] |
| **Weaknesses** | Belum memiliki brand awareness; butuh pendampingan onboarding awal di lapangan (`07`, `14`) [Assumption] |
| **Opportunities** | 30.000+ bengkel urban belum memakai software vertikal; integrasi distributor sparepart di fase lanjutan (`07`) [Estimate] |
| **Threats** | Churn tinggi jika pemilik bengkel malas input stok; POS horizontal masuk ke fitur bengkel (`15`) [Estimate] |

## Strategi TOWS
- **SO**: Gunakan keunggulan template part siap pakai untuk mempercepat konversi pilot di klaster bengkel padat.
- **WO**: Sediakan jasa input awal katalog 100 part terlaris gratis saat minggu pertama untuk menekan churn.
- **ST**: Kunci retensi lewat riwayat servis pelanggan & reminder WhatsApp otomatis (biaya pindah tinggi).
- **WT**: Jangan bakar budget iklan nasional sebelum *cohort* 30 hari pertama membuktikan churn <= 4,5%.
